# Wavebird Python publisher integration

The versioned `wavebird-publisher-server` wheel connects a Python application to the Wavebird `/v1` Test lifecycle. Banner, Native and Clip use the same saved-project placement, consent, timing, generation and reporting contract. Test activity is nonpayable. Keep the Server Test Key and Preference Secret on the server.

Install the exact wheel from its matching published release and verify its SHA-256 against that release before installation. Install FastAPI and an ASGI server for the [minimal FastAPI example](examples/fastapi_app/README.md). The package's `PublisherConfig` accepts only a Test key, exact public origins, saved formats and approved sizes. It rejects browser-selected project or format overrides. GPC suppresses placement and consent changes without blocking the publisher's model generation.

`wavebird_publisher.fastapi.create_app` provides same-origin placement, consent, generation and browser-module routes. Supply the real server-validated session ID and existing abortable model response hooks; the defaults in the example deny or raise. The package binds one placement and generation to a turn and queues ordered `started`, `finished` or `failed` reports only with a trusted server-side Wavebird job ID. Reporting delay or failure does not hold the publisher's model; verify accepted reports and durable facts independently. Its included coordinator is for a single-process Test app. A multi-worker app must connect shared turn state and retain the duplicate and report guards before use.

The wheel also includes a browser host module, served by the FastAPI route at `/api/wavebird/browser.js`. Mount it beside the existing result, connect real session/model/CMP hooks, and pass the saved timing, consent mode and slot height. That browser module loads the official `https://api.wavebird.ai/v1/render.js` renderer to display the creative and send its rendering lifecycle. The Python server alone does not render an ad. Keep the model result independent of consent, No-Fill or ad timing. Verify the visible creative, same request/slot reporting and durable nonpayable project fact for each enabled format. Clip additionally needs visible playback and completion evidence.
