# wavebird Python server integration (0.1.0b1)

This framework-neutral package handles authenticated server-side placement, consent synchronization and trusted generation reports. It uses each publisher's saved project settings and exact public origin. It accepts only a `sk_test_` Server Test Key. The key and Preference Secret stay on the server. Download the versioned wheel from the [Python 0.1.0b1 release](https://github.com/wavebird-ai/api/releases/tag/python-v0.1.0b1) and verify its SHA-256 against that release before installing it. This optional Python package does not change the JavaScript `.4` installation.

GPC suppresses ad placement and Consent changes; it does not block the authenticated publisher's model generation.

Install the versioned wheel into your Python application and create `PublisherConfig` from your saved Dashboard project and server-only environment values. Implement `authorize(request)` with your real session check; missing or failing authorization denies access. Map your framework's request to `PublisherRequest`, then return the status, headers and body from `placement_post`, `consent_get` or `consent_post` on same-origin routes. Call `authorize_generation` before entering your existing model stream, and attach your own stream cancellation and lifecycle reporting. `report_generation` accepts a **server-trusted Wavebird job ID**, never a browser-supplied identifier, and only `started`/`finished`/`failed` events.

The [FastAPI example](examples/fastapi_app/README.md) wires all same-origin Wavebird routes. Its two publisher hooks intentionally deny access and reject generation until they are connected to the app's real session and model stream. The browser still needs the public wavebird renderer and established browser lifecycle integration. Mount a reserved slot, connect the placement and consent routes, and verify a visible creative plus its durable project fact. A Python placement response does not prove an ad was shown.

The local synthetic tests cover two separate origins and projects, session denial, foreign Origin, GPC, consent denial, No-Fill, timeout, malformed input and invalid Live key. There are no QA-wrapper URLs, ports, project IDs or saved sessions in the package source. A served browser render, durable fact and independent publisher installation remain **NOT RUN** for this new general package.
