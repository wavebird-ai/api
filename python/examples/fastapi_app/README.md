# FastAPI publisher example

This example connects the versioned `wavebird-publisher-server` package to an existing FastAPI app. Install the exact wheel from its matching published release after checking its SHA-256, then set the saved project values as server-only environment variables. Use this journal-enabled example only with a release that includes `mount_fastapi` and `turn_journal_path`. Keep the Server Key and Preference Secret out of Git, responses and browser code. Test use is nonpayable; production requires its own approved project and key.

`run.py` reads `WAVEBIRD_CLIENT_ID`, `WAVEBIRD_SECRET_KEY`, `WAVEBIRD_PREFERENCE_SECRET`, `WAVEBIRD_PUBLIC_ORIGINS`, `WAVEBIRD_SURFACE_ID`, `WAVEBIRD_PLACEMENT_KEY`, `WAVEBIRD_JOB_TYPE`, `WAVEBIRD_LOCALE`, `WAVEBIRD_TIMING`, `WAVEBIRD_CONSENT_MODE`, `WAVEBIRD_APP_NAME`, `WAVEBIRD_APP_DOMAIN`, `WAVEBIRD_ALLOWED_FORMATS`, `WAVEBIRD_ALLOWED_SIZES`, `WAVEBIRD_SIZE_FORMATS_JSON`, `WAVEBIRD_GDPR_APPLIES`, `WAVEBIRD_POSITION_HINT` and `WAVEBIRD_TURN_JOURNAL_PATH`. Use the exact saved project values. `WAVEBIRD_PUBLIC_ORIGINS` is a comma-separated list of separately registered origins, including scheme and port. `WAVEBIRD_ALLOWED_SIZES` uses `320x50,300x250` syntax. `WAVEBIRD_SIZE_FORMATS_JSON` maps every saved size to its eligible formats, for example `[[320,50,["banner"]],[300,250,["native","clip"]]]`. The journal path must be absolute on durable storage shared by the app's workers on one host.

Replace the session and generation hooks in `publisher_hooks.py` before accepting publisher traffic:

1. `session_id_for_request` must return the real server-validated app session ID. `authorize_publisher_request` derives its decision from that hook. The default denies access.
2. `existing_generation` must call the app's existing model stream and preserve its response and cancellation. Its default raises an error. Generation must continue when consent is refused, an ad is unavailable or placement is slow.

Call `create_app(..., host_app=your_existing_app, turn_journal_path=...)` to mount the package routes without replacing the host's routes or middleware. Mount a reserved ad container beside the AI result and load the package's same-origin `/api/wavebird/browser.js` module. Supply its real session and model response consumer hooks, the saved timing, job type and slot size, and a real CMP or Wavebird dialog. Resolve the model consumer only after its output is presented, and call the returned browser disposer from the app's sign-out and page teardown handlers. The browser module loads the official `/v1/render.js` creative renderer. The journal binds placement and generation by validated session and turn and retries ordered server-trusted job reports across local workers and restarts. It does not establish a multi-host or serverless deployment. Verify a visible Banner, Native or Clip creative, its rendered event and a durable nonpayable project fact. No-Fill leaves the slot empty; Clip also needs actual playback/completion evidence.

If your FastAPI app is mounted below a path such as `/app`, load the module from that same mount and pass `apiBasePath: "/app"` to the browser helper. The base path accepts only local path segments; it cannot redirect API calls to another origin.

The local adapter test uses two synthetic publishers and proves auth, exact Origin, GPC, No-Fill and generation routing. It does **not** prove a served ad or a real publisher session.
